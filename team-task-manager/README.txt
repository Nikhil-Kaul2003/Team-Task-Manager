TEAM TASK MANAGER

Project Description:
Team Task Manager is a full-stack web application developed using Next.js, Prisma ORM, and PostgreSQL. The application helps teams manage projects and tasks efficiently with authentication and role-based access control.

Features:
1. User Signup and Login
2. JWT Authentication
3. Role-Based Access Control (ADMIN & MEMBER)
4. Create Tasks
5. View Tasks
6. Delete Tasks
7. Mark Tasks as DONE
8. PostgreSQL Database Integration
9. Responsive Dashboard UI
10. Railway Deployment

Tech Stack:
Frontend:
- Next.js
- React.js
- JavaScript

Backend:
- Next.js API Routes
- Node.js

Database:
- PostgreSQL
- Prisma ORM

Authentication:
- JWT
- bcryptjs

Deployment:
- Railway

How to Run Project:
1. Install dependencies using:
   npm install

2. Setup .env file:
   DATABASE_URL="your_database_url"
   JWT_SECRET=mysecretkey123

3. Push Prisma schema:
   npx prisma db push

4. Run project:
   npm run dev
